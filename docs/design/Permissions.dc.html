mdp needs two macOS permissions

macOS asks for these so mdp can move the cursor and type for you, and read your mouse and keyboard when they're plugged into this Mac.

Accessibility Move the cursor and type on this Mac
Granted
Input Monitoring Read the mouse and keyboard plugged into this Mac

mdp never records keystrokes. Input goes only to your paired Windows PC, encrypted, and nothing is stored.
