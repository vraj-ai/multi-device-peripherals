# Triage labels

| Role | Label |
|---|---|
| Untriaged | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Agent can pick up | `ready-for-agent` |
| Needs a human | `ready-for-human` |
| Won't do | `wontfix` |
| Pipeline lifecycle (pipeline-owned, never set by hand) | `goals:planned` `goals:ready` `goals:in-progress` `goals:blocked` `goals:failed` `goals:done` `goals:cancelled` |
| Area | `area:core` `area:link` `area:windows` `area:macos` `area:ui` `area:ci` |
| Final proof needs the real Mac + PC | `needs-mac-hardware` |
